Post in chat, never in a file, and only after every Short of the request is built. Group the Shorts by day under
a `# DD MON` heading, with one section per Short:

````
## 1 · 13:00 IST · 02NOV_slot1_1300_ronaldo_kholood_hattrick.mp4 · 33.1s

**TITLE**
```
Ronaldo SCORED 3 in 15 minutes 😳 #halo try this sound #shorts
```
**DESCRIPTION**
```
<paragraph 1: hook then concrete facts, leading with the player's full name>

<paragraph 2: payoff, ending in the debate question>

Follow for more football shorts ⚡

#halo <5-7 topic hashtags> #Football #Soccer #FootballShorts #Futbol #shorts #fyp #viral
```
**TAGS**
```
<14 topic tags>, football shorts, soccer shorts, football news, futbol, football edit, football facts
```
**PINNED COMMENT**
```
<the CTA rephrased as a question> 👀
```
````

Checklist for every Short (CD has had to repeat these):
1. **TITLE** = `<hook, about 28 characters, exactly ONE ALL-CAPS curiosity word> 😳 #halo try this sound #shorts`.
   Keep `#halo` in the title, because the #halo titles are the channel's audience growers.
2. Four **separate** fenced blocks, labelled TITLE / DESCRIPTION / TAGS / PINNED COMMENT.
3. The description includes the literal line `Follow for more football shorts ⚡`.
4. **13–15 hashtags**, with `#halo` first. **20–24 tags.** Count them.
5. Heading: `## N · HH:MM IST · filename.mp4 · duration`.
6. What-If Shorts use the same format. Description = the question, plus one line of real context, plus "Tell us in the comments."
7. Keep the facts in the description identical to the script. Never add claims the script didn't verify.
